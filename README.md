# 🌸 Momentum — Student Wellness Companion

> A thoughtful web application designed for students to track daily moods, log health metrics, and journal thoughts in a clean, calming environment.

---

## 📸 Key Features
* **Mood Tracking:** Interactive mood selector (Happy, Calm, Neutral, Anxious, Stressed, Overwhelmed) and subjective happiness score slider.
* **Daily Health Check-in:** Log sleep duration, track exercise completion, and keep quick nutrition notes.
* **Reflective Journaling:** Private, distraction-free space for daily reflection and thought processing.
* **Progress Dashboard:** Visual mood trends and entry history tracking over time.

---

## 🛠️ Tech Stack
* **Framework & Tooling:** React, Vite, TypeScript
* **Styling & UI Components:** Tailwind CSS, shadcn/ui
* **Icons & Assets:** Lucide Icons
